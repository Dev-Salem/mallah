Problem

Graduates do not need more content.

02

They need direction, proof, and a clear moment when they know they are ready to apply.

01 | Theory

Knowledge is not the bottleneck.

University and the internet provide information. What learners still lack is a sequence that turns theory into visible capability.

02 | Noise

The path is fragmented.

Tutorials, roadmaps, resume tips, and job boards all live in separate worlds. Beginners waste energy stitching them together.

03 | Readiness

No one knows when to move.

Many apply too early, while others keep learning forever. The missing signal is measurable readiness backed by proof.

Saudi Context

This gap matters even more now.

03

Saudi digital transformation creates demand for talent, but many learners still reach graduation without a structured bridge into entry-level technical work.

Local Need

Digital employability is a national priority. The market wants capability, not just course completion.

Graduate Reality

Students still face path confusion, weak portfolios, and unclear readiness even after serious effort.

Product Opportunity

A guided bilingual platform fits both the regional market need and the learner context better than a generic global tool.

Deep Dive 1

The roadmap is the engine.

Mallah organizes each path into stages and topics, tracks progress, and uses project milestones to turn passive study into visible advancement.

  • Four predefined technical paths for cleaner decision-making.
  • Path → stage → topic structure instead of random tutorial hopping.
  • Project-gated progression so momentum leads to proof.
  • Topic-level tracking with AI lesson support where language understanding helps.

Roadmap View

Deep Dive 2

Learning becomes recruiter-visible proof.

Portfolio Hub and Resume Builder turn completed work into evidence that can be shown, shared, and tailored for opportunities.

  • Verified skills unlock from roadmap and completed projects.
  • Project records become shareable, not buried.
  • ATS-aware resume building stays grounded in real data.
  • The bridge from progress to presentation becomes native to the platform.

Deep Dive 3

Job readiness becomes measurable.

The Opportunity Analyzer and Application Tracker connect jobs to skills, missing topics, action plans, and follow-through.

  • Paste a job description or review the Saudi opportunity feed.
  • See matched skills, missing skills, and a practical next-step plan.
  • Map missing requirements directly back to the roadmap.
  • Track the full application lifecycle without losing analysis context.

Architecture

The system was built for reliability.

10

The technical architecture favors modularity, secure data handling, and clear boundaries between learner-facing features and platform logic.

Frontend

Experience Layer

  • Next.js 16
  • React 19
  • App Router
  • Bilingual interface

Application

Logic Layer

  • Feature-based modules
  • Server actions
  • Zod validation
  • Rule-based logic first

Data + AI

Trust Layer

  • Supabase / PostgreSQL with RLS-aware access
  • OpenAI used only for tasks that need language understanding
  • Evidence over fabrication across resume and analyzer flows
  • Admin visibility without compromising learner ownership
